# Phishing Attack Simulation and Detection

## Objective
To simulate phishing attacks in a controlled environment and implement a detection system using Python.

## Tools Used
- HTML, CSS
- Python
- Regex

## Features
- Fake login page for phishing awareness
- URL-based phishing detection system
- Keyword and pattern analysis

## Disclaimer
This project is strictly for educational purposes and does not target real users or systems.

## Outcome
Improved understanding of phishing techniques and defense mechanisms.
